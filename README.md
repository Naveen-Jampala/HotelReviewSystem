# Hotel Review System

A Java-based console application that allows users to view hotels, submit reviews and ratings, and filter/sort existing reviews.

## Features
- **View Hotels**: Display all available hotels along with their average user ratings.
- **Add Reviews**: Submit custom ratings (1.0 to 5.0) and written reviews for hotels.
- **Filter Reviews**: Filter hotel reviews based on a minimum rating threshold.
- **Sort Reviews**: Sort reviews by Highest Rating, Lowest Rating, or Newest First using Java Streams.

## Tech Stack
- Java (JDK 11+)
- Core Java (OOP, Collections Framework, Java Streams API)
